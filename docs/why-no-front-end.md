# Views without a front end

The daily work is matching two sets of records, explaining exceptions and reviewing evidence. Ask for the daily review, propose a group, log the investigation and have a second person approve it. The database retains the records; the coding agent runs the recipes.

npm run view writes three read-only HTML reports. npm run docs writes statements, case worksheets and match review records in brand.json colours. No server or application front end is needed for the base. Files are private outputs, not an online service.

A screen adds mobile access, a side-by-side matching grid, bulk selection, authenticated review, live feeds and interactive drill-down. This base has none of those. Local access requires the database and files on that machine; it does not offer offline sync between devices. Enterprise DNA can scope those features for a business version with its identity, volume and control requirements.

/new-view adds a saved read-only report. /customise changes the schema and routines with a tested migration. No browser action moves money, posts a journal or sends a message.
